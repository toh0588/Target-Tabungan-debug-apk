# Artefak Bangunan — Target Tabungan

Folder ini berisi artefak hasil build APK Debug terbaru untuk repositori **`toh0588/Target-Tabungan-debug-apk`**.

## Isi Folder
- **`Target-Tabungan-debug.apk`** — File APK Debug Android yang siap dipasang langsung di perangkat Android.
- **`output-metadata.json`** — Metadata versi dan varian APK hasil build Gradle.
- **`SHA256SUMS.txt`** — Checksum SHA-256 untuk memverifikasi keutuhan file APK.
